# Roxy Trade

Private source repository for the Roxy Trade project.

## Release status

**Not live for funded automatic trading.** The Build 17 trading-engine package passed offline tests, but the production V1 route-pinning and atomic approval functions are not deployed. Existing production emergency-stop constraints must remain intact.

No Robinhood API keys, Supabase service-role secrets, or credentials should ever be committed here.

The first engineering milestone is a reviewed, independently tested supervised order workflow, not automatic trading activation.
